---
title: Weekly calendar view
description: Review a single training week on desktop and mobile.
---

Choose **Week** in the calendar to focus on Monday through Sunday.
Use the previous/next arrows or **Current week** to navigate. The selection
is remembered in this browser; a calendar URL with `?view=week` opens the
weekly view directly.

Desktop shows seven day columns. Mobile stacks the days vertically.
Session names wrap so long workout titles remain readable. Existing event
dialogs, context menus, templates, cycle displays and drag-and-drop behavior
are reused.

The summary below the days uses the existing **Planned / Done**, **Planned**
and **Done** options, including duration, distance, elevation and available
training-load figures. It respects the calendar's sport filter.

This contribution adds the calendar view only. Plan-week editing, copying or
moving entire weeks and other planning-workspace features are separate work.
