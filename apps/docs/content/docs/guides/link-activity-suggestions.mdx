title: Link a completed activity to a session
description: Link a completed activity to a session.
---

Open a planned session or competition and find **Linked activity**. Up to three unlinked activities from the same local day are suggested, with the same sport first and then the closest start time. Choose **Link** to associate one.

The dropdown groups same-day activities before nearby activities within the existing three-day window. Labels show the time and distance, and the date for other days. Linking uses the existing API and permissions; suggestions do not link anything automatically. Only activities loaded in the calendar are considered.
